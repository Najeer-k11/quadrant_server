How to read these numbers

  • Measured on an i7-13620H laptop with a compiled build over loopback, with 64 keep-alive connections and no TLS. Your hardware and workload will differ.
  • Each figure is the median of three 6-second runs. Most runs varied by under 5%, so treat smaller differences as noise.
  • The plain routes are close to doing nothing, so they show the most overhead. Handlers that do real work will see smaller differences between before and after.
  • The load generator runs on the same machine. It reached about 400,000 req/s against the bare C++ server, well above every Dart result here, so it should not be what limits those. That C++ server was held back by it, though, which is why this page compares it by CPU time.
